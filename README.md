# Australia 2028 eclipse — trip research

Working research notes on where to stand for the **total solar eclipse of Saturday, 22 July 2028**
in Australia: path membership per town, July cloud climatology, and what lodging actually exists in
the small towns along the track.

**Read it as a site: <https://rageling.github.io/aus2028-eclipse/>**

Every factual claim carries a source link; anything unverified is marked `TBD — verify`. These are
one group's working notes rather than a reference work — where it matters, follow the link and read
the source. That goes double for anything about eye safety.

This repo is generated. It is a published subset of a private planning repo, synced by script, so
pull requests here can't be merged — but corrections are genuinely welcome as issues, particularly
if you can point at a source.
